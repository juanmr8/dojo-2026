# 02-blur-text

What this piece explores: a text-splitting primitive (`TypeSplit`: line, word, char; SSR text, screen-reader sentence, no-JS and reduced-motion fallbacks), drivers that decide when an effect plays (`InView`, `Scrub`), a first effect, `BlurIn`, and a copyable preset, `BlurTitle`, in load, in-view and scrub flavours.
